# FidCard — téléchargements

Vos cartes de fidélité sur Windows et Android, 100 % locales : pas de compte, pas de cloud.

Ce dépôt ne contient que les **installateurs publiés** de FidCard (le code source est privé).
Présentation complète : [nevennit.github.io/#/projet/fidcard](https://nevennit.github.io/#/projet/fidcard).

## Installer

1. Ouvrez la [dernière version](https://github.com/NevennIT/fidcard-releases/releases/latest).
2. Windows 10 / 11 (64 bits) : téléchargez le fichier `*_x64-setup.exe` et lancez-le.
   L'application n'étant pas signée, Windows SmartScreen peut afficher un avertissement :
   cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
3. Android 7 ou plus récent (64 bits) : téléchargez le fichier `*_android-arm64.apk` sur le téléphone
   et ouvrez-le, en autorisant l’installation depuis cette source si Android le demande.

# FidCard — downloads

Your loyalty cards on Windows and Android, 100% local: no account, no cloud.

This repository only holds the **published installers** of FidCard (the source code is private).
Full presentation: [nevennit.github.io/#/projet/fidcard](https://nevennit.github.io/#/projet/fidcard).

1. Open the [latest release](https://github.com/NevennIT/fidcard-releases/releases/latest).
2. Windows 10 / 11 (64-bit): download the `*_x64-setup.exe` file and run it.
   The app is not signed, so Windows SmartScreen may show a warning:
   click "More info", then "Run anyway".
3. Android 7 or later (64-bit): download the `*_android-arm64.apk` file on the phone
   and open it, allowing installs from this source if Android asks.
